# 审查规则

## 敏感数据扫描
- 日志中打印手机号/身份证/银行卡号
- 响应报文中包含明文敏感字段
- 密码/密钥/AK/SK 硬编码在代码中
- 敏感数据未脱敏直接存储或传输

## 加密合规
- 使用已弃用的加密算法（DES/RC4）
- 密钥硬编码或密钥管理不规范
- 未使用 HTTPS/TLS 传输加密
- 国密（SM2/SM3/SM4）合规要求

## 认证鉴权
- 敏感接口缺少权限注解
- 水平越权风险：用户 A 可操作用户 B 的数据
- 内部接口暴露到外网无额外鉴权

## SQL注入检测
- 动态 SQL 拼接用户输入
- MyBatis 中使用 ${} 而非 #{}
- OrderBy 动态拼接未做白名单校验
