# 审查规则

## 幂等性
- 写接口（下单/转账/退款）是否有幂等保障
- 幂等 key 选取是否合理
- 是否有数据库唯一索引兜底
- MQ 消费端是否处理重复消息

## 资金一致性
- 金额是否使用 BigDecimal（禁止 double/float）
- BigDecimal 构造使用 new BigDecimal("0.1") 而非 new BigDecimal(0.1)
- 资金操作是否在事务内
- 跨系统资金操作是否有 TCC 或补偿机制
- 每笔资金变动是否生成唯一流水号

## 状态机
- 状态是否通过枚举定义而非魔法值
- 是否存在非法跳转（已退款 → 再次退款）
- 状态更新是否带版本号/乐观锁
- 更新 SQL 是否带状态条件：WHERE status='OLD'

## 限额风控
- 单笔交易金额是否校验上下限
- 日累计/月累计交易金额是否有控制
- 同 IP/同设备短时间高频交易是否有风控拦截

## 账务合规
- 记账是否满足借贷平衡
- 会计日期是否使用业务日期
- 冲正/撤销是否有完整账务记录
