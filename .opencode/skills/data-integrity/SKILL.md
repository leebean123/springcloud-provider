# 审查规则

## 事务边界
- 跨表操作事务注解（@Transactional）是否合理
- 事务传播行为是否正确
- 跨库操作是否使用分布式事务或柔性事务
- 事务内是否存在远程调用（长事务风险）
- 事务方法内部 try-catch 是否导致异常被吞、事务未回滚

## 补偿机制
- 跨系统调用失败是否有补偿机制
- 补偿方式是否合理（TCC/Saga/本地消息表）
- 补偿是否幂等
- 补偿失败是否有告警和人工介入

## 审计日志
- 关键操作（转账/下单/改密）是否有审计日志
- 审计日志是否包含：操作人、时间、IP、变更前后
- 审计日志是否不可篡改

## 对账检查
- 内部账务是否每日对账
- 外部渠道是否定期对账
- 对账不一致是否有处理策略
